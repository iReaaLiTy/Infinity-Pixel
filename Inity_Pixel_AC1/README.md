# Pacote AC1 · Inity Pixel

Preparação de design e handoff técnico em 30/09/2026. Equipe: Murilo Cassetti, Heitor Crispim, Pedro Ferreira e Juan Carlos.

## Comece aqui

1. Abra `galeria.html` para revisar as artes e ouvir a trilha.
2. Leia `GDD_AC1.md` e aprove/ajuste as propostas com o grupo.
3. Cole o conteúdo de `PROMPT_CLAUDE_AC1.md` no Claude Code dentro deste projeto.
4. Copie os cards de `TRELLO_E_ENTREGA.md`, atribua responsáveis reais e anexe recursos.

## Divisão para concentrar o uso do Astra

**Claude:** código, cenas, integração dos assets, UI, testes técnicos, correções comuns e build. Use o mesmo prompt e checkpoints; não é necessário passar cada alteração pelo Astra.

**Astra:** pacote inicial de design; revisão de uma decisão importante; segunda análise se o mesmo bug continuar após diagnóstico do Claude; revisão final de aderência à AC1. Ao voltar, traga erro exato, arquivos alterados e teste que falhou. Essa é uma organização de trabalho, sem promessa de economia percentual ou mudança de limites da conta.

**Grupo:** decisões finais, playtest, papéis, responsáveis do Trello e envio pelo Game Designer.
